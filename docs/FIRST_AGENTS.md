# First agents checklist (Phase 8)

Use this when recruiting 5–10 Philippine agents (not a code task).

1. Point custom domain at the Hatchbox / DigitalOcean app; set `APP_HOST` (no `https://`).
2. Confirm R2/S3, SMTP, and (optionally) PayMongo keys on the host.
3. Send each agent: signup → [/guide](/guide) → Brand kit → one listing pack → download PNG → paste caption. Pro accounts also use **Share** on Listings (Facebook / WhatsApp / copy link). Free accounts see Share on Pro.
4. Create a dedicated operator (`admin@listingpack.local` locally). Do **not** flag agent accounts as admin. Operators log in at [/admin/login](/admin/login). Use [/admin/users](/admin/users) to grant Pro / reset quota. Watch [/admin/failures](/admin/failures) for poster OOMs and failed packs.
5. Collect feedback on copy quality, quota confusion, and poster reliability for a week before Phase 9.
